Desa Woewutu

Dashboard rekapitulasi Dusun A–D, anak kampung, KK dan pemilih agregat, TPS, hasil suara resmi, serta laporan bersama untuk admin dan petugas dusun.

Akses terbatas · Data tersimpan pada database online yang Anda konfigurasi

Masuk aplikasi

Gunakan akun yang dibuat oleh admin. Pendaftaran akun publik tidak tersedia.

Pengaturan koneksi database

Isi URL proyek dan publishable/anon key dari Supabase. Key ini boleh ada di browser hanya karena hak akses dibatasi oleh RLS. Jangan pernah masukkan service_role/secret key.

Jika database belum dibuat, ikuti file PANDUAN.md di paket unduhan. Aplikasi ini belum terhubung ke database sampai Bapak mengisi konfigurasi proyek sendiri.
